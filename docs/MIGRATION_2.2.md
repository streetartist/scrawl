# Migrating to Scrawl 2.2

Scrawl 2.2 makes the Rust/Bevy engine the only implementation.

## Package imports

Replace every old import:

```python
from scrawl import Game, Scene, Sprite2D
```

with:

```python
from scrawl import Game, Scene, Sprite2D
```

`scrawl_v2` is not installed and intentionally raises `ModuleNotFoundError`.

## Pygame removal

- Pass image paths to `Sprite2D.add_costume()` instead of Pygame Surface objects.
- Use string keys such as `"space"` and `"left"` in `@on_key`.
- Use tuples or Scrawl `Vector2` values for positions.
- PygameGUI, Cat, TkGUI, cloud variables and the Pygame utility module were v1-only and have been removed.

## New Sprite2D layout API

```python
sprite.set_dimensions(160, 48)
sprite.z_index = 10
```

`size` remains a uniform scale. `width` and `height` set the base render dimensions.

## Physics node composition

The old `PhysicsSprite` shortcut is no longer generated by the IDE. Use the
Godot-style composition instead:

```python
body = RigidBody2D("Ball")
shape = CollisionShape2D()
shape.set_circle(18)
visual = Sprite2D("Visual")
visual.set_dimensions(36, 36)
body.add_child(shape)
body.add_child(visual)
```

`RigidBody2D` exposes `gravity_scale`, `linear_velocity`, `mass`, `friction`
and `bounce`; `CollisionShape2D` owns the collider geometry.
